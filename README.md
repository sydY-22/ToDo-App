# ToDo-App:
create todo list app using json and tkinter.

# Purpose:
Is to help increase productivity, organizing and completing daily goals.

# Goals:
- Create an app that can be quickly accessed (todo app).
- Then, quickly update, save and delete data (json data).
- Small formed app with simple user interface (tkinter).
